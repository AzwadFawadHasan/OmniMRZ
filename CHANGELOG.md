All notable changes to this project will be documented in this file.

## [0.2.0] - 2026-02-08

### Added
- Screenshot detection feature using ScreenshotScanner library
- Warning output when image is detected as screenshot
- Comprehensive test suite with pytest
- MANIFEST.in for proper package distribution
- Development dependencies for testing and code quality

### Changed
- Updated version to 0.2.0 to reflect new feature addition
- Improved package configuration with modern standards

### Fixed
- Version consistency between pyproject.toml and package __init__.py
