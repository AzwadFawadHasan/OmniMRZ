Comprehensive Features

MRZ Extraction

  • PaddleOCR-based text extraction
  • Intelligent line clustering
  • Automatic MRZ type detection (TD1/TD2/TD3)
  • OCR error correction (O→0, S→5, B→8)
  • Handles corrupted/misaligned MRZs

Structural Validation

  • ICAO-9303 format compliance
  • Exact line-length enforcement
  • Field-level format verification
  • Character set validation
  • Early-exit gating for invalid layouts

Checksum Validation

  • Full ICAO-9303 algorithm implementation
  • Document number checksum
  • Date of birth checksum
  • Expiry date checksum
  • Composite checksum verification

Data Parsing

  • Structured JSON output
  • Name, DOB, nationality extraction
  • Document type & number
  • Gender and personal number
  • Clean, accessible data format

Logical Validation

  • Expired document detection
  • Future date-of-birth detection
  • Implausible age detection
  • DOB ≥ expiry detection
  • Gender value validation

Fraud Detection

  • Screenshot detection
  • Image quality assessment
  • ELA (Error Level Analysis)
  • Confidence scoring
  • Detailed detection reasons

Installation

Quick Install

pip install omnimrz

That's it! No complex dependencies or PATH configurations required.

First Steps

from omnimrz import OmniMRZ

omni = OmniMRZ()
result = omni.process("passport.jpg")
print(result)

Requirements

  • Python 3.8 or higher
  • pip package manager
  • ~500MB disk space (for PaddleOCR models on first run)
  • Internet connection (first-time model download)
